# APB-Controlled-I2C

An FPGA-based I2C controller connected to an APB (Advanced Peripheral Bus) interface. The design allows a processor or bus master to configure and control I2C communication through memory-mapped registers.

## Project Purpose

This project was developed as part of the **NTI (National Telecommunications Institute) training in Digital Design on FPGA**. It applies digital design concepts to the implementation of a reusable APB-controlled I2C peripheral.

## Features

- APB interface for register-based control
- I2C master communication
- Configurable I2C operation through control and status registers
- FPGA-oriented RTL design
